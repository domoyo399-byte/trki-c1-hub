为什么“一次导入”能写入三库？

你的三个 GitHub Pages 都位于同一个域名 domoyo399-byte.github.io 下。 浏览器的 localStorage 按“域名 / origin”隔离，而不是按仓库路径隔离，所以这个学习中心能在同一浏览器里更新三套独立的数据库 key。 请从 GitHub Pages 打开本学习中心；如果只是从 iPhone“文件”里本地打开 HTML，它不会和线上网站共享数据。
